Open the evidence desk
Is this a prediction exchange?

PredictKit builds prediction applications. Its reference apps support forecasts, YES / NO / VOID outcomes, and calibration. They are off-chain simulations; there is no real-money trading or custody.

What is connected to Solana today?

The registry now compiles to Solana bytecode and passes 28 tests in a local SVM. An executed local demo creates a question, records forecasts and resolves it. Wallet connection and public deployment remain open; the reference apps remain off-chain. Inspect the recorded local execution.

Can I use Codex or Claude?

You can use either coding tool to work on this local repository. They are not connected as native Studio runtime workers. The implemented live runtime provider uses OpenAI’s Responses API.

What happens when I export?

You receive a local ZIP with generated artifacts and the run record. Pitch and technical demo files are drafts to review. Export does not publish an app, create a public repository, or submit to an event.
