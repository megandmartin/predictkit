# Before public release / competition entry

- [ ] Named team members and affiliations are eligible; shared toolkit use clarified where needed.
- [ ] Current portal fields, deadlines and video limits reviewed.
- [ ] Clean tested runtime version lock and complete setup steps.
- [ ] A real multi-agent run with observed usage and output, not only fixtures.
- [ ] One meaningful Solana integration with reproducible proof.
- [ ] Browser tests on the exact app being demonstrated.
- [ ] Third-party licenses, starter version and original contribution disclosed.
- [ ] No secrets, private prompts or unconsented participant data in public files.
- [ ] Actual validation results, with denominator; no invented traction.
- [ ] Pitch and technical demo separately recorded and accessible to judges.
- [ ] Humans approve public repository, branding, claims and final submission.
- [ ] Portal confirmation retained after the human submits.
