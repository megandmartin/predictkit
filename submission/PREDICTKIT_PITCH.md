# PredictKit — working pitch draft
Recording target: about three minutes, subject to the current submission form. This is the toolkit's pitch, not a participant application's pitch. Replace PENDING statements with measured evidence before recording.

## 0:00–0:25 / The problem
Building a prediction application involves more than a screen with YES and NO. A builder must define a useful question, connect the right infrastructure, handle resolution, coordinate implementation and prove that the result works. Our hypothesis is that short build events lose too much time on that coordination.

## 0:25–0:55 / The product
PredictKit gives builders a domain-specific starting point and a visible agent team. The founder defines a brief, independent roles work in parallel, and the founder approves the plan before the build. The result is inspectable code, domain rules and a launch pack tied to evidence.
