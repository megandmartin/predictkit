# Public source provenance

This public release derives from the supplied PredictKit v0.2 source and subsequent local runtime, design, skill and Solana work reviewed on 28 September 2026. It contains project source, synthetic examples, tests and generic operating documents.

The public tree is separate from the private working directory. Private runtime records, one-run authorization plans, credentials, personal handoff material, compiler caches, installed dependencies and screenshot archives are excluded. Proposed personal assignments were replaced with generic roles. Third-party font licenses accompany the fonts.

The recorded Solana receipt replaces one private absolute compiler path with a repository-relative path. Its `publication` object records the original receipt hash and the redaction. Transaction data, signatures and account values are unchanged. The public JSON and viewer have their own hashes; the original hash is provenance metadata, not the hash of the derivative.

`SOURCE_MANIFEST.json` inventories this reviewed public source snapshot. It replaces the private handoff's historical baseline inventory. Hashes establish consistency, not identity, correctness or live execution. [Publication verification](../evidence/PUBLICATION.md) states the actual checks and remaining gaps.
