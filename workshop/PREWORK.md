# Participant prework
Complete at least the day before the event.

Use the same tagged toolkit release as the host. Confirm Python 3.11+, open the local dashboard and run the reference rehearsal. A full live event additionally needs the host-verified runtime and model configuration, a model available to your own authorized account, a chosen cost limit and the event's tested Solana environment.

Bring a brief with a real user, a specific problem, one exact question, deadline/source/VOID rule and one differentiated interaction. Do not bring a seed phrase, a wallet holding real assets, confidential client data or a half-configured collection of runtimes.

Host must confirm: clean clone-and-run on two machines; provider credentials and rate limits; separate test accounts; known RPC/network; fallback materials; mentor availability; actual competition submission requirements; local demo capacity and user-data consent.

The shipped v0.2 source alone does NOT satisfy a live on-chain workshop preflight. Its missing integration gates are in docs/BUILD_PLAN.md.
